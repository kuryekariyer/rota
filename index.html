    Gelişmiş: Google trafik verisi Kapalı

    İsteğe bağlı. Anahtar girilirse durak sırası da trafikli ve kapı seviyesinde hesaplanır. Anahtar sadece bu cihazda saklanır.

    Anahtar nasıl alınır?
    1. console.cloud.google.com → proje oluştur → faturalandırmayı aç.
    2. Places API (New) ve Routes API'yi etkinleştir.
    3. API anahtarı oluştur; "Websites" ile bu siteye, API listesiyle bu 2 API'ye kısıtla.
    4. Bütçe uyarısı kur, anahtarı buraya yapıştır.
